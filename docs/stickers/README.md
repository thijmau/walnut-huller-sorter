# Safety Stickers

Because the machine has multiple moving parts, transports liquids and is powered
by electricity, there are multiple risks involved using it. The function of
these stickers is to warn people (_especially those who've never read the
manual_) of specific hazards and their locations on the machine.

The hazards themselves are extensively described
in [the safety manual](../manuals/safety-manual.md), which should be read before
using and/or building the machine. The symbols are based
on [ISO 7010](https://en.wikipedia.org/wiki/ISO_7010) to make them widely
recognizable and consistent with the international standard.

Below is a table which summarizes the stickers that are recommended to be placed
on the machine, with their respective location and meaning.
